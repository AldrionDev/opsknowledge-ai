## Known limitations

- A single run over a small dataset is indicative, not statistical.
- Actual model outputs are nondeterministic; repeated live runs can differ.
- Keyword-based figures are heuristic proxies, not measures of factual correctness: paraphrases cause false negatives, keywords inside wrong or negated statements cause false positives, and forbidden lists are not exhaustive.
- Similarity-score distributions are descriptive only; no threshold is derived or applied.
- Database verification checks chunk identity, metadata and content against the repository corpus; it does not establish which model computed the stored embedding vectors.
- Provider token usage is reported only for completed responses; usage of failed, timed-out or retried attempts is unknown and may still be billed.
- The worst-case output-token bound is not a total cost bound: input tokens and provider pricing are not included.
